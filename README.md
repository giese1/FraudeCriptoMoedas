# Fraude Criptomoedas

Este é um projeto de ciencia de dados e machine learning.

O dataset usado contem dados de transações financeiras da criptomeda Ethereum.

Alguns atributos são:

- FLAG: se a transição é fraude ou não.
- Avg_min_between_received_tnx: Média de tempo de transações recebidas na conta em minutos.
- Sent_tnx: Numero total de transações enviadas.
- Received_tnx: Numero total de transações recebidas.

Foi usado o modelo de machine learning XGBoost para a previsão de fraudes.

O modelo obteve a acuracia de 97% nos dados de teste.
